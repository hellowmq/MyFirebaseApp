# MyFirebaseApp

> Historical Android/Firebase learning project, preserved for reference.

This Java Android experiment connects a small app to Firebase Realtime Database, Storage, and Cloud Messaging. It reflects the Firebase and Android SDK versions used when the project was created, not a current production architecture.

## Before running

- Register your own Android app in a Firebase project and use your own client configuration.
- Review Firebase Authentication and database/storage rules before connecting any real data.
- Do not treat the configuration committed for this historical demo as reusable production configuration.
- The project has not been revalidated with current Android Studio, Gradle, or Firebase SDKs.
